# Customer Retention Analytics

## Business Question
Which customer and account characteristics are associated with churn, and how accurately can churn risk be predicted?

## Stack
Python · Pandas · DuckDB SQL · scikit-learn · Matplotlib

## What I did
- Cleaned and validated customer data
- Calculated churn KPIs
- Compared churn across contract and customer characteristics
- Used SQL for grouped business analysis
- Built a logistic-regression churn model
- Evaluated model discrimination with ROC-AUC
- Translated findings into business implications and limitations
